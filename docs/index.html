Claude Desktop

3 Ways to Use Custom Models in Claude Desktop

  • MCP Model Bridge (lib/mcp_model_bridge.py): Auto-registered in claude_desktop_config.json. Call ask_custom_model and list_custom_models directly from any Claude Desktop chat.
  • Developer Mode Third-Party Inference: Automatically enables allowDevTools: true in developer_settings.json so you can point Claude Desktop to Metis, AvalAI, or our local proxy.
  • Local Anthropic ↔ OpenAI Proxy (lib/desktop_proxy.py): Run ~/.agent-bridge/start-proxy.sh (or start-proxy.cmd / start-proxy.ps1 on Windows) on port 4789 to translate OpenAI-only providers into Anthropic /v1/messages.
ChatGPT Desktop & Open GUIs

Codex Provider + Local Proxy + Native Drop-Ins

  • Codex / Developer Desktop: Automatically writes [model_providers.<provider>] to ~/.codex/config.toml.
  • Local OpenAI Gateway Proxy: Exposes http://127.0.0.1:4789/v1 with optional model remapping and /health diagnostics.
  • 100% Native Custom-API Desktop GUIs: Because consumer ChatGPT Desktop hard-pins chatgpt.com, ./install-agent.sh also lets you one-click install Cherry Studio, Chatbox, or Jan with native Metis/AvalAI support.
